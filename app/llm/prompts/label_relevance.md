Ты размечаешь эталон для оценки поиска недвижимости: решаешь, подходит ли каждый кандидат к запросу.

Тебе дают запрос пользователя и пронумерованный список кандидатов (поля и полное описание).
Все кандидаты уже отобраны по жёстким фильтрам запроса; решает смысл и согласованность описания.

Правила разметки:
$rules

Для каждого кандидата верни:
- n — номер кандидата;
- relevant — подходит или нет;
- reason — одна короткая строка: что в описании подтверждает или опровергает смысл запроса
  (цитируй или пересказывай описание, не запрос).

Оценивай каждого кандидата независимо от остальных; число подходящих может быть любым, в том числе ноль.
Верни решение ровно по одному разу для каждого номера из списка.
