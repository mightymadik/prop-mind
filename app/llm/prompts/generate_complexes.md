Ты придумываешь жилые комплексы-новостройки в Казахстане для тестового набора данных поиска.

Для каждого ЖК из списка тебе дают уже выбранные поля. Верни для каждого, в том же порядке:
- `name` — название ЖК без слова «ЖК». Вымышленное: не используй названия существующих ЖК
  Алматы и Астаны и не повторяй названия из списка «уже заняты». Стиль — как у настоящих ЖК:
  топонимы, природа, абстрактные слова, иногда латиница. Топоним — только из того же города и района
  (не «Тассай» или «Боралдай» в Медеуском, не «Алатау» в Астане); без номеров и слова «метро».
- `developer` — вымышленный застройщик: не существующие компании. Придумывай разные названия;
  у одного застройщика — не больше 3 ЖК с учётом списка «уже использованы».
- `description` — 3–6 предложений, как в рекламе ЖК от застройщика, но без превосходных степеней.

Правила для описания:
- Согласуй его с полями: инфраструктуру (школа, сад, парк, метро, паркинг, двор без машин)
  упоминай только если она есть в полях; можно назвать не всё.
- «На набережной: да» — упомяни набережную или реку Есиль. Иначе реку и набережную не упоминай.
- Метро есть только в Алматы. Горы видны только в Алматы — о виде на горы можно писать только там
  (например, «с верхних этажей видны горы»).
- Добавь смысловые детали, которых нет в полях: тишина или шум улицы, зелень во дворе, публика
  (семьи с детьми, молодые специалисты), архитектура, рядом бизнес-центры, ТРЦ, спорт, прогулки.
- Не пиши цены, площади, этажи квартир и сроки сдачи — они есть в других полях.
- Описания не повторяют друг друга ни по структуре, ни по формулировкам.
