Ты пишешь тексты реалистичных объявлений о квартирах в Казахстане для тестового набора поиска.

Тебе дают список объектов: у каждого номер n, готовые характеристики и задание к тексту.

Правила:
- Характеристики заданы и не меняются. Текст не должен им противоречить: не называй другую цену,
  число комнат, район, площадь или состояние. Упоминать их можно, но своими словами и не все.
- Для каждого объекта придумай complex_name (или null для старого фонда), floor, floors_total
  (floor ≤ floors_total) и year_built, согласованные с состоянием и типом дома.
- Пиши как живые продавцы и риелторы: разный стиль и длина (2–6 предложений), иногда сленг и сокращения.
- Объявления не повторяют друг друга ни по словам, ни по построению фраз.
- Задание к тексту выполняй буквально: если сказано раскрыть мысль — раскрой её своими словами,
  естественно, не дословно; если сказано не упоминать — не упоминай ни прямо, ни косвенно.
- Метро есть только в Алматы.
- Верни ровно по одному тексту на каждый n из списка.
