### 1. Все поля схемы для LLM обязательны

- **Что сломалось.** «аренда 3-комнатной в Алматы» (d03) терял город в 2 прогонах из 3.
- **Почему.** Не ошибка разбора: ключа `city` не было уже в сыром JSON модели
  (`{"deal_type":"rent","rooms":[3],"features":[],...}`). Поля с default не входят в
  `required` схемы, и structured outputs разрешают модели их пропускать — она
  пропускала поля непредсказуемо (`districts` то был, то нет), в том числе нужные.
- **Что сделали.** В `build_parser_schema` все поля без default: модель обязана
  явно решить по каждому полю, «нет фильтра» пишет как `null` / `[]` / `""`.
  `SearchFilters` для кода не изменился. Правка общая — для всех полей, не для d03.
- **Результат.** d03: 1/3 → 3/3. Разброс между повторами 3% → 0%. Задержка та же.
